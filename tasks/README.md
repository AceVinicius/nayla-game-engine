# Tasks

Work is defined in **GitHub issues**, one per task, using the `Task` issue template (`.github/ISSUE_TEMPLATE/task.md`). The PR that implements a task says `Closes #N`; dependencies are GitHub "blocked by" links.

`done/` keeps tasks 001–013, written before the move to issues, as history. Do not add new files here.

Rules for writing a task: `.claude/rules/tasks.md`.
